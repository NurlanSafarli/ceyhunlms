# QA yoxlaması — 27 oktyabr 2026

## Düzəlişlər

- **Mobil dil seçimi:** toxunma brauzeri `focusout` hadisəsində `relatedTarget=null` verdikdə menyu seçim düyməsinin `click` hadisəsindən əvvəl bağlanırdı. Boş fokus hədəfi artıq seçim menyusunu bağlamır. Kənara toxunma, Escape və fokusun başqa elementə keçməsi ilə bağlanma saxlanılır. Xəta əvvəlki build-də regresiya testi ilə təkrar yaradıldı; düzəlişdən sonra test keçir.
- **Toxunma sahələri:** mobil dil seçimi, menyu, mövzu dəyişmə, qeydiyyat və qalereya düymələri ən azı 44 px ölçüdədir. Dil düyməsində ikiqat toxunma böyütməsinin qarşısını alan `touch-action: manipulation` tətbiq edildi.
- **Əlaqə paneli:** admin “Tədris istiqamətləri” bölməsini gizlətdikdə sıfır koordinatlı gizli element paneli səhvən aktivləşdirirdi. Gizli bölmə artıq aktivləşdirmir.
- **Oxunaqlılıq:** terminal illüstrasiyasındakı solğun şərh mətninin kontrastı artırıldı.

## Yoxlama əhatəsi

- Node.js/SQLite API, autentifikasiya, CSRF, qeydiyyat, CMS, qruplar, vəsaitlər, imtahanlar, fayllar və ehtiyat nüsxələr.
- Chromium masaüstü və mobil toxunma emulyasiyası: AZ/ENG/RU dəyişməsi və yadda saxlanması, fokus itkisi, kənara toxunma, klaviatura, mövzu dəyişmə, menyu, qeydiyyat və xəta halları, FAQ, qalereya, loqo, PDF sillabus və əlaqə paneli.
- GitHub Pages: `/ceyhunlms/` alt yolu, admin giriş ünvanları, PDF/şrift/favikon yüklənməsi, WhatsApp müraciəti və mobil dil seçimi.
- Mobil ölçülər: 320, 360, 390, 430, 768, 844 px; hər birində üç dil. Üfüqi daşma və əsas header düymələrinin ölçüləri yoxlandı.
- Masaüstü/planset ölçüləri: 320, 390, 768, 1024, 1101, 1200, 1280 px.
- axe-core WCAG A/AA yoxlaması: üç dil × iki mövzu; admin giriş, panel bölmələri və məlumat əlavəetmə formaları. Bunlar tam əl ilə əlçatanlıq sertifikatlaşdırmasını əvəz etmir.
- Sınaqlar ayrıca müvəqqəti/in-memory bazalarda aparılıb; istifadəçinin real bazası dəyişdirilməyib.

## Məhdudiyyətlər və saxlanılan brend tələbi

- Real iPhone/Android cihazına çıxış yoxdur. Mobil davranış Chromium toxunma emulyasiyası ilə yoxlanıb. WebKit yükləmə domenləri mühitdə HTTP 403 ilə bloklandığından Safari mühərrikində yoxlama baş tutmayıb. `relatedTarget=null` hadisə ardıcıllığı ayrıca testlə əhatə olunub; real Safari nəticəsi kimi təqdim edilmir.
- Narıncı loqo şüarı (`#FD6A02`, 7–8 px) açıq fonda avtomatik kontrast xəbərdarlığı yaradır (təxminən 2.65–2.90:1). İstifadəçinin açıq brend rəngi tələbinə uyğun saxlanılıb; bu qeyd ümumi mətnin əlçatanlıq nəticəsi ilə qarışdırılmamalıdır. Digər yoxlanan elementlərdə qalan axe pozuntusu yoxdur.
- QA bütün mümkün brauzer, cihaz və admin tərəfindən gələcəkdə yazılacaq məzmun üçün xətasızlıq zəmanəti deyil.

## iOS üçün əlavə düzəliş

İlkin fokus düzəlişindən sonra istifadəçinin iOS problemi barədə bildirişinə əsasən toxunma cihazlarında `details/summary` menyusu standart HTML `select` ilə əvəz edildi. Safari seçimi öz native menyusunda açır; seçim xüsusi klik/fokus bağlanması məntiqindən asılı deyil. SVG bayrağı header-də qalır. Input şrifti 16 px-dir, beləliklə iOS-un fokus zamanı avtomatik böyütməsi təşviq edilmir. Masaüstündə əvvəlki SVG bayraqlı menyu saxlanılır. Lokal və Pages build-lərində dil dəyişməsi və yadda saxlanması testləri keçdi. Real Safari cihazında yoxlama məhdudiyyəti qüvvədədir.
